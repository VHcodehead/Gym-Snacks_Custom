# Gym Snacks — custom business website

Custom marketing site built for Gym Snacks and maintained by me for the business.

- **Stack:** Next.js 16.2.2 (App Router), React, TypeScript, Tailwind CSS
- **Hosting:** Railway (`railway.json`), pnpm
- **SEO:** per-page metadata, canonical URLs, structured data and keyword-targeted content

## Development

```sh
pnpm install
pnpm dev      # http://localhost:3000
pnpm build
```
